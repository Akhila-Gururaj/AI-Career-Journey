1. What is Python?
Python is a high-level, interpreted, and easy-to-learn programming language. It is widely used for web development, data science, artificial intelligence, machine learning, automation, and software development.

2. What is a Variable?
A variable is a named memory location used to store data. The value of a variable can be changed during program execution.

3. Name Four Data Types
int – Stores whole numbers.
float – Stores decimal numbers.
str – Stores text or characters.
bool – Stores Boolean values (True or False).

4. What is the purpose of print()?
The print() function is used to display information or output on the screen. It helps programmers see the values of variables and the results of program execution.

5. Why do we use comments?
Comments are used to explain the code and improve its readability. They are ignored by the Python interpreter and do not affect the execution of the program.

Git Basics
6. What is Git?
Git is a distributed version control system used to track changes in source code. It allows developers to save different versions of a project, collaborate with others, and restore previous versions if needed.

Why do companies use Git?
Companies use Git because it helps developers:

Track changes in code.
Work together on the same project.
Maintain different versions of software.
Recover previous versions if mistakes occur.
Manage large software projects efficiently.

Git = A tool to manage your code versions.
GitHub = A website where you store and share Git repositories.
